# Simple Python To-Do List

Простой консольный менеджер задач (To-Do List), написанный на Python. Проект создан для практики базовых концепций языка и работы с файловой системой.

## 🚀 Особенности
- Добавление новых задач.
- Просмотр списка всех задач.
- Отметка задачи как выполненной `[x]`.
- Удаление задач.
- **Сохранение данных**: задачи сохраняются в файл `tasks.json` и не исчезают после перезапуска программы.

## 🛠️ Технологии
- Python 3.x
- Встроенные модули `json` и `os` (не требует установки сторонних библиотек).
